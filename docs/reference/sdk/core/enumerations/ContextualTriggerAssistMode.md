# Enumeration: ContextualTriggerAssistMode

Controls when a while-writing trigger offers help. Defaults to `Proactive`.

## Enumeration Members

### Balanced

> **Balanced**: `"balanced"`

Offers help occasionally.

***

### OnDemand

> **OnDemand**: `"on_demand"`

Offers help only when the user asks.

***

### Proactive

> **Proactive**: `"proactive"`

Offers help as the user writes.
