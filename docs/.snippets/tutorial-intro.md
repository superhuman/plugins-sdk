You need a Superhuman account with:

- A [Pro plan][pricing] or higher, to install and use the {{ kind }} in :superhuman-go: Go.
- [Doc Maker access][hc_doc_maker] in your :superhuman-docs: Docs workspace, to create the Pack.
- A :superhuman-go: Go client installed ([Chrome][go_chrome] or [Edge][go_edge] extension, or the [Mac or Windows desktop app][go_desktop]).

There are two options for how to build the {{ kind }} in this tutorial, with a tab for each:

- **:octicons-terminal-16: CLI** - Work locally with the `packs` command line tool.
- **:octicons-browser-16: Pack Studio** - Work entirely in the browser, with nothing to install.
